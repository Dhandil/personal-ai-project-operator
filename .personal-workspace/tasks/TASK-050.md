# TASK-050：明确项目创建后的工作流引导

## 目的与范围

让用户在新建项目后直接理解阶段文件由谁创建、由谁更新、当前阶段该做什么，以及何时需要用户审批。

## 验收条件

- 页面明确说明阶段文件由系统初始化，无需用户上传，由 Agent 读取并更新；
- “待开始”和“已存在”分别解释阶段状态与文件状态，避免被理解为上传要求；
- 当前阶段展示首要操作、需要读取的产物和推荐下一步；
- 核对并修正“用户场景”“Discovery 验证”等阶段的产物映射，避免错误重复；
- 提供从项目总览进入工作流、再进入执行或阶段材料的清晰路径；
- 跳过流程继续要求 Agent 建议、用户填写理由并决定；
- 补充首次使用引导和相关浏览器测试。

## 边界与交接

- 不要求用户上传系统已经创建的阶段文件；
- 若当前版本尚不能直接启动 Agent，必须明确提示现状和可执行入口，不伪装为自动执行；
- 完成并验收后再执行 TASK-051。
