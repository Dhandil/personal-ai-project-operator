# TASK-054：统一全页面视口布局与滚动边界

## 目的与范围

在 TASK-053 的两级导航外壳上，统一全部现有页面的高度、间距、信息密度和滚动边界，尽量消除桌面端页面级纵向滚动。

## 验收条件

- 覆盖工作台、项目列表、新建项目、项目概览、工作流、目标、任务、角色、执行控制台、运行报告、审批、问题与决策、历史和服务状态页面；
- 应用外壳使用可用视口高度，一级侧栏和顶部二级导航保持稳定，内容区使用剩余空间；
- 在 1280×800 等常见桌面窗口中，标准数据状态下页面标题、当前状态和主要操作无需滚动即可看到；
- 不必要的大标题、重复说明、过宽间距和卡片留白被压缩，但正文、表单和关键状态保持易读；
- 长任务列表、阶段列表、报告、审批、历史和执行时间线使用局部滚动、分页、折叠或清晰分区，不让整个页面无限增长；
- 不隐藏或删除治理事实、审批理由、错误、风险和审计信息；
- 480px 等窄屏允许自然纵向滚动，内容顺序、焦点和字号可用，页面不得横向溢出；
- 增加覆盖主要页面的桌面首屏、局部滚动、窄屏和键盘可达性回归测试；
- 完整 `npm run verify` 通过。

## 边界与交接

- 不改变任务状态、审批语义、工作流、Agent 执行或 Git 行为；
- 不用小于正常可读范围的字号换取密度；
- 完成后生成 TASK-054 独立报告和 GOAL-011 检查点报告，等待独立验收。
