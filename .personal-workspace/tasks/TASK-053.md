# TASK-053：实现一级侧栏与二级页签导航

## 目的与范围

将现有导航重构为两层信息架构：左侧侧栏只切换总模块，内容区顶部只展示当前模块的下属页面。

## 验收条件

- 左侧一级导航仅包含：工作台、项目、执行、治理、系统；
- 工作台顶部二级导航包含：项目列表、新建项目；
- 项目顶部二级导航包含：概览、工作流、目标、任务、角色；
- 执行顶部二级导航包含：执行控制台、运行报告；
- 治理顶部二级导航包含：审批、问题与决策、历史；
- 系统顶部二级导航包含：服务状态；
- 当前项目名称或上下文在应用外壳中持续可见；
- 当前一级模块和二级页面同时具有清晰的视觉选中态及可访问语义；
- 所有既有页面和深链接仍可直接访问，刷新后导航选中状态正确；
- 桌面端侧栏稳定；窄屏一级导航可收起，二级导航可完整访问且页面无横向溢出；
- 更新导航模型测试和桌面/窄屏 Playwright 回归场景。
