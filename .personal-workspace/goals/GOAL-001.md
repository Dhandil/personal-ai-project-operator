# GOAL-001：建立可运行工程

## 目标

建立能够安装、启动、构建和执行质量检查的全栈 TypeScript 工程，为后续领域功能提供稳定基础。

## 验收

- Fastify 和 React 开发骨架可以运行；
- 根级格式、Lint、类型、测试和构建命令可执行；
- 通过本目标检查点后仍需用户批准，才可启动下一目标。
