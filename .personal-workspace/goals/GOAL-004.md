# GOAL-004：完成新项目初始化

## 目标

让用户从空目录和一个想法创建受治理的新项目，并在任何写入和 Git 操作前审核完整预览。

## 验收

- 未批准时没有副作用；
- 批准后创建治理目录、项目索引和 Git 基线提交；
- 用户可通过中文 Web 向导完成流程。
