# GOAL-014：V0.5 支持已有项目与通用项目模板

## 目标

安全导入已有项目，并使用模板支持 Coding 与知识生产两类真实项目。

## 验收

- 已有项目经过只读预览和用户批准后导入，不覆盖现有文件或历史；
- Coding 和知识生产模板共享治理模型但拥有不同角色和工作流；
- 模板支持轻量定制，不引入复杂设计器；
- 两类临时项目端到端验收通过。

## 状态

- 本目标为路线草案；只有 GOAL-013 检查点接受后才能申请启动。
